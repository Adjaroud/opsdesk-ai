# MFA — Téléphone perdu ou validation impossible

Procédure fictive KB-004. Ne jamais demander ou communiquer un code MFA ou de récupération. Si le téléphone est perdu, contacter le support via le canal officiel pour vérification d'identité, révocation et réenrôlement. Aucun contournement MFA n'est autorisé. Pour une notification inattendue, refuser la validation et signaler un incident sécurité.
