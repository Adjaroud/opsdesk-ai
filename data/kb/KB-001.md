# VPN — Connexion distante

Procédure fictive KB-001. Consulter d'abord les incidents VPN connus. Vérifier que la connexion Internet fonctionne et noter le message d'erreur exact, le système utilisé et l'heure du problème. Relancer une fois le client VPN officiel DemoConnect puis valider le MFA habituel. Ne jamais désactiver le pare-feu, partager un mot de passe ou demander un code MFA. En cas d'incident collectif, ne pas réinstaller le poste : attendre les informations du support. Aucun délai de résolution n'est garanti. Si le problème persiste, proposer un ticket avec le message d'erreur et l'impact métier.
