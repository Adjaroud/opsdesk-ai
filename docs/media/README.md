# Visuels de démonstration

Visuels publiés pour la présentation GitHub :

Les visuels proviennent de l'application réellement utilisée avec Gemini, sans réponse ou trace fictive ajoutée. Les originaux `demo_f.mp4` et `trace_et_sources.mp4` restent exclus de Git ; seul le montage final est publié. La capture ne contient ni clé, ni jeton de session, ni chemin personnel visible.

Parcours de capture : salarié fictif → envoyer le VPN → montrer sources et trace réelles → demander le brouillon → montrer sa justification → approuver → montrer l'identifiant SQLite.

Masquer les clés, les fichiers `.env`, les en-têtes de session et les chemins personnels. Utiliser uniquement les salariés et données fictifs. Ne pas remplacer les réponses par des captures de tests simulés présentées comme un vrai LLM.
